# 🎬 React YouTube Clone

Bu proje, YouTube benzeri bir video izleme uygulamasıdır.  
React, React Router, Axios ve RapidAPI (YouTube API) kullanılmıştır.

---

## 🚀 Özellikler
- 🔍 Arama özelliği
- ▶️ Video oynatma (React Player)
- 💬 Yorumlar bölümü
- 📺 Kanal detayları
- 📱 Responsive tasarım
